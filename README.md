# موتوتک

فروشگاه و مجله Next.js که محصولات و نوشته‌ها را از وردپرس هدلس می‌خواند. تا وقتی نشانی وردپرس تنظیم نشده باشد، نمونه‌های داخل پروژه نشان داده می‌شوند.

## اجرا

```bash
npm install
npm run dev
```

`npm run build` خروجی استاتیک را در پوشه `out` می‌سازد. محتویات همان پوشه را در `public_html` سی‌پنل بگذارید.

## وردپرس

پوشه `wordpress/mototec-headless` را در `wp-content/plugins/` کپی کنید و افزونه «موتوتک هدلس» را فعال کنید. ووکامرس هم باید فعال باشد تا محصولات بیایند.

در تنظیمات وردپرس، صفحه «موتوتک هدلس» کلید API را نشان می‌دهد. `.env.example` را به `.env.local` کپی کنید. نشانی API همین است:

`https://admin.mototec.ir`

فقط `MOTOTEC_API_KEY` را از همان صفحه در `.env.local` بگذارید. محصول، دسته، نوشته و دستهٔ مجله از `index.php?rest_route=/mototec/v1/…` روی همان نشانی خوانده می‌شوند.

محصول، قیمت، موجودی، عکس و توضیح از ووکامرس می‌آید. برند، مدل، ویژگی‌ها، مشخصات، اقلام جعبه، گارانتی، وضعیت ارسال و نکته در زبانه «موتوتک» محصول است. مشخصات را خط‌به‌خط به شکل `برچسب: مقدار` بنویسید.

مجله همان نوشته‌های منتشرشده وردپرس است. عنوان، متن، خلاصه، تصویر شاخص، نویسنده و دسته روی سایت می‌آیند.

بعد از تغییر در وردپرس دوباره `npm run build` بگیرید و `out` را آپلود کنید.

واتساپ، اینستاگرام، تلگرام، ایمیل، آدرس و ساعت پاسخگویی تا وقتی در متغیرهای `NEXT_PUBLIC_*` خالی باشند روی سایت نشان داده نمی‌شوند.

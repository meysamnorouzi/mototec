# موتوتک

فروشگاه Next.js برای موتوتک که محصولات را از ووکامرس هدلس می‌خواند. تا وقتی نشانی وردپرس تنظیم نشده باشد، چهار محصول اولیه از همین پروژه نمایش داده می‌شوند. دسته‌های خالی در منو ساخته نمی‌شوند.

## اجرا

```bash
npm install
npm run dev
```

## اتصال به وردپرس

1. ووکامرس را روی وردپرس نصب کنید.
2. فایل `wordpress/mototec-product-fields.php` را در `wp-content/plugins/mototec-product-fields/` بگذارید و فعال کنید.
3. در ووکامرس یک کلید REST با دسترسی خواندن بسازید.
4. `.env.example` را به `.env.local` کپی کنید و این مقدارها را پر کنید:

- `WORDPRESS_URL`
- `WC_CONSUMER_KEY`
- `WC_CONSUMER_SECRET`

5. دسته‌ها را در ووکامرس بسازید و محصول را داخل دسته و زیردسته قرار دهید. نام، قیمت، قیمت قبل از تخفیف، موجودی، عکس، گالری، توضیح کوتاه، توضیح کامل و SKU همان فیلدهای خود ووکامرس هستند. برند، مدل، ویژگی‌ها، مشخصات، اقلام جعبه، گارانتی، وضعیت ارسال و نکته در زبانه «موتوتک» محصول ثبت می‌شوند.

مشخصات فنی را خط‌به‌خط به شکل `برچسب: مقدار` بنویسید. ویژگی‌ها و اقلام جعبه را هر کدام در یک خط بنویسید.

بعد از ویرایش محصول، فروشگاه حداکثر تا دو دقیقه کش را تازه می‌کند. برای به‌روزرسانی فوری:

```bash
curl -X POST https://mototec.ir/api/revalidate -H "x-revalidate-secret: YOUR_SECRET"
```

واتساپ، اینستاگرام، تلگرام، ایمیل، آدرس و ساعت پاسخگویی تا وقتی در متغیرهای `NEXT_PUBLIC_*` خالی باشند روی سایت نشان داده نمی‌شوند.

# موتوتک

فروشگاه و بلاگ Next.js که محصولات، دسته‌ها و نوشته‌ها را در مرورگر از API وردپرس می‌خواند. دادهٔ نمونه در پروژه نیست. محصول یا نوشتهٔ تازه، بدون بیلد دوباره، با باز کردن سایت دیده می‌شود.

## اجرا

```bash
npm install
npm run dev
```

`npm run build` خروجی استاتیک را در پوشه `out` می‌سازد. یک‌بار محتویات همان پوشه را در `public_html` سی‌پنل بگذارید. فایل `.htaccess` داخل `out` باید بماند تا آدرس محصول و نوشتهٔ تازه باز شود.

## وردپرس

پوشه `wordpress/mototec-headless` را در `wp-content/plugins/` کپی کنید و افزونه «موتوتک هدلس» را فعال کنید. ووکامرس هم باید فعال باشد تا محصولات بیایند.

نشانی API این است:

`https://admin.mototec.ir`

فروشگاه و بلاگ در مرورگر از `index.php?rest_route=/mototec/v1/…` خوانده می‌شوند و به کلید API نیاز ندارند. فقط `https://mototec.ir`، `https://www.mototec.ir` و لوکال‌هاست اجازه دارند. افزونه را یک‌بار دیگر روی وردپرس بگذارید تا این محدودیت و خواندن بدون کش اعمال شود. بعد از آن، انتشار محصول یا نوشته کافی است.

در همان صفحهٔ تنظیمات، دکمهٔ «وارد کردن محصولات نمونه» چهار محصول قبلی فروشگاه را با همان نام، قیمت، دسته و عکس در ووکامرس می‌سازد. ووکامرس باید فعال باشد.

محصول، قیمت، موجودی، عکس و توضیح از ووکامرس می‌آید. برند، مدل، ویژگی‌ها، مشخصات، اقلام جعبه، گارانتی، وضعیت ارسال و نکته در زبانه «موتوتک» محصول است. مشخصات را خط‌به‌خط به شکل `برچسب: مقدار` بنویسید.

بلاگ همان نوشته‌های منتشرشده وردپرس است. عنوان، متن، خلاصه، تصویر شاخص، نویسنده و دسته روی سایت می‌آیند.

بعد از عوض کردن ظاهر سایت دوباره `npm run build` بگیرید و `out` را آپلود کنید. خودِ محصول و نوشته به این کار نیاز ندارند.

واتساپ، اینستاگرام، تلگرام، ایمیل، آدرس و ساعت پاسخگویی تا وقتی در متغیرهای `NEXT_PUBLIC_*` خالی باشند روی سایت نشان داده نمی‌شوند.
